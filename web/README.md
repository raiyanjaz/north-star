# Browser assets

- `app.js` and `style.css` are generated by `pnpm build`. Edit `frontend/` instead.
- `index.html` is the handwritten shell. The Python handler injects the selected
  city configuration and initial state request before the map scripts load.
- Leaflet, MapLibre and their bridge are vendored browser dependencies.
- The GeoJSON files are fallback display geography, not routing data.

Pure display logic lives in `frontend/domain/dispatch-model.mjs`, outside this
served directory. `frontend/styles.css` imports source styles in a deliberate
order; feature styles and responsive layout rules remain separately editable.
